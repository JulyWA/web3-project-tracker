# Web3 Project Tracker

This repository stores shareable Web3 project tracking notes exported from July's local watchlist and pre-watchlist workflow.

## Structure

- `watchlist/`: projects already under active watchlist tracking.
- `pre-watchlist/`: RootData-passed projects still under lightweight observation.
- `archive/`: reserved for graduated or rejected historical project notes.

## Privacy

This export is intentionally sanitized. It should not include local automation state, webhook URLs, tokens, wallet/account records, or private manual notes.
