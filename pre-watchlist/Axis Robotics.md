## 2. 初始判断

Hack VC 领投 $12M 种子（顶级机构+顶级金额+Nomad/Pi 跟投）是本批次唯一硬指标齐全的项目。产品 2026-03 已在 Base 主网上线，10 万+ 贡献者日均 3-4 次提交，采用 hybrid 模式：真实收入分成（fiat）+ 质量评分 points + 未来 token 奖励，文档明确写 supply/分配/vesting 待定。用户通过 beta hub 登录、浏览任务、实时操控机器人完成物体交互，质量评分决定收益（Perfect > 大量低质）。这种质量导向+人工操控设计天然抑制脚本农场，非常适合有一定人力+AI 经验的团队组织多账号真人参与。风险点：早期项目质量评分算法不透明、时间投入较大、机器人任务学习曲线；建议 1-3 账号试水评估单账号 ROI。
